# StarCleaning - Professional Cleaning Services Web Application

A modern, responsive, and fully-featured front-end web application built for a professional cleaning service company. It provides users with a seamless experience to explore services, learn about the expert team, check pricing, and get in touch.

## 🚀 Features

- Responsive Navigation Bar: Smooth mobile and desktop menu handling.
- Hero Section: Engaging introduction with clear Call-to-Action (CTA) buttons.
- Services Showcase: Detailed cards for different cleaning packages (Deep Cleaning, Commercial, Carpet & Upholstery Care, Office Cleaning).
- Meet Our Experts: Team member profile section highlighting certified professionals with a unified brand aesthetic.
- Interactive Elements: Easy-to-use booking triggers, contact sections, and custom icons using Lucide React.
- Modern UI/UX: Built with a clean, minimalist, and professional green color theme tailored for a cleaning brand.
